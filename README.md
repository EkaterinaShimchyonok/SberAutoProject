# SberAutoProject
Модель для предсказания совершения целевого действия (Api)

«СберАвтоподписка» — это сервис долгосрочной аренды автомобилей для физлиц. 

Целевое действие — события типа «Оставить заявку» и «Заказать звонок»
(ga_hits.event_action in ['sub_car_claim_click', 'sub_car_claim_submit_click','sub_open_dialog_click', 'sub_custom_question_submit_click', 
'sub_call_number_click', 'sub_callback_submit_click', 'sub_submit_success','sub_car_request_submit_click']).

Задачи
1 Научиться предсказывать совершение целевого действия
(ориентировочное значение ROC-AUC ~ 0.65) — факт совершения
пользователем целевого действия.
2 Упаковать получившуюся модель в сервис, который будет брать на
вход все атрибуты, типа utm_*, device_*, geo_*, и отдавать на выход
0/1 (1 — если пользователь совершит любое целевое действие).

Файлы формата JSON для проверки работы модели находятся в PyCharm проекте.
